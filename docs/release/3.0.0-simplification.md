# Release simplification review

Three independent reviews covered reuse, quality, and efficiency for the release
changes through `a7be391f` and the pending landing CEL 3 cutover.

Applied two focused improvements: Bitcoin publication preparation reads the
proposed state once and indexes prior resources by id; fresh asset resolution
indexes observed publications and hashes each accepted inline body once while
preserving first-match attachment selection. Removed two unnecessary/unsafe
TypeScript lint constructs in provider and recovery diagnostics. Public types
now compile examples of hosted, Bitcoin, snapshot and recovery contracts.

Deferred broader refactors: hosted read concurrency and repeated freshness
checks would change network/error ordering; constructor dependency objects
would alter the public shape; network/DID helper consolidation has differing
validation semantics; local verification consolidation would widen internal
interfaces. None is required to preserve the documented release behavior.

Verification: 59 focused provider, resolution, publication and recovery tests
passed (171 assertions); workspace typecheck passed. Full package suites passed
before these localized changes. Final lint, package and browser checks are
recorded in the release verification receipt.
