Hosted publication on the Originals Protocol, behind `hostedPublication` (off). A signed-in author publishes an Original under a did:webvh alias in their own namespace, controlled by their Turnkey identity key; the host accepts only the hosted layout, checks each resource against the Original's uploaded asset log, and serves it with the media type that log declares (the host does not verify the log; readers do). The CEL-era host key shapes are gone.
